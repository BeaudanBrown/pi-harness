# Triage Labels

| Canonical role | GitHub label |
| --- | --- |
| needs triage | `needs-triage` |
| needs information | `needs-info` |
| ready for agent | `ready-for-agent` |
| ready for human | `ready-for-human` |
| will not fix | `wontfix` |

Use one lifecycle-state label at a time. Existing `bug`, `enhancement`, and `documentation` labels describe category rather than lifecycle state.
